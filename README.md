# AI Lecture Assistant

An AI-powered study assistant that transforms university lecture recordings into searchable and interactive study material.

## Planned Features

- Lecture audio upload
- Speech-to-text transcription
- AI-generated summaries
- Semantic search
- Chat with lectures
- Flashcard generation
- Quiz generation

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI

### Database
- PostgreSQL
- pgvector

### AI
- Whisper
- Ollama
